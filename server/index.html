Local-first task planner

Your tasks are files. Not rows in somebody's database.

watsmytask keeps every task as plain markdown in a folder you own. Open it in Obsidian, edit it in vim, grep it, commit it to git. Delete the app tomorrow and your work is still sitting there, readable.

Install it
$ npx watsmytask

Runs on 127.0.0.1. No account, no cloud, no telemetry. The only time it reaches the network is when you ask it to download an AI model.

My work

The screen that tells you where to start

Momentum, staleness and what needs attention are computed every time the files are read — never stored. No cached signal can drift out of step with your folder, and there is no migration to run when the rules change.

No model is consulted here. This grouping is plain arithmetic over dates and log entries, so it is instant, correct with the network off, and identical every time you load it.

Attention is given as words, not a score. "92" tells you nothing. Overdue by 2 days tells you what to do.

The optional chat

It proposes. You decide.

Ask a local model to tidy up, and it does not touch your disk. Every write it attempts comes back as a diff of a specific file, with Apply and Discard beside it. Nothing has changed when you see it.

That is what makes a small model on your own laptop useful rather than risky. A 3B model will sometimes pick the wrong task. The cost of that is a diff you decline.

Applying re-runs the operation rather than replaying the stored patch. If the file moved on in the meantime, the server refuses and shows you the new diff instead of overwriting work it never saw.

↳ Auto-apply exists as a setting. It defaults to off, and it should stay there.

Workspaces

A workspace is a folder. All of them alike.

Make one in the app, or make one in Finder — a folder with a tasks/ in it is a workspace the next time the planner looks. Each gets its own board, its own lanes, its own cards.

The assistant only ever sees the workspace you are in. Not as a filter it applies, but because it is handed that one folder and holds no reference to any other. It cannot list, search, read or write across the boundary, and it is not told the others exist.

Ask about work in another workspace and the honest answer it has is "not in this one".

The rest of it

Details that keep the folder trustworthy

Surgical writes

Setting a field rewrites only the lines holding that field. Adding a log entry only appends. Your hand-written formatting, your comments and any frontmatter keys the app has never heard of all survive untouched.

Lanes are yours

No fixed To Do / Doing / Done. Lanes live in board.md and you name them. Rename one and a single line changes — the id is the identity, so no task is rewritten.

Nothing goes invisible

Hand-write a status: no lane matches and the column appears anyway. A task you cannot see is worse than a column you did not ask for.

Edits from outside

A file watcher picks up changes you make in Obsidian or vim and pushes them straight to the open tab. The folder is the source of truth, not the app's memory of it.

Git as undo

Point it at a vault that is a git repo and every applied change becomes a commit, with an Undo next to it in History. Your version control, not a proprietary trash can.

Faster than asking

The command palette ⌘K exists so the chat is never the quickest way to do a simple thing. "Mark X done" should be two keystrokes, not a sentence and a model round-trip.

Install

Two minutes, no admin password

Nothing is written outside your own user folder, on either platform.

Not a terminal person

Download the installer, double-click, done. It fetches Node for you if you do not have it.

  1. Download watsmytask-installer.zip from the latest release and unzip it.
  2. Double-click the installer for your computer and read READ ME FIRST.txt.
  3. Allow it past the one security prompt — Open Anyway on macOS, Run anyway on Windows.

It leaves a launcher in your Applications folder on a Mac, and on your Desktop on Windows.

Download the installer

Always the newest version. About 15 KB — the installer fetches the rest.

Comfortable in a terminal

One command. It starts the server and opens your browser.

$ npx watsmytask
$ npm install -g watsmytask

Requires Node 20.11 or newer. Your tasks land in ~/watsmytask-vault — back that folder up and you have backed up everything.
